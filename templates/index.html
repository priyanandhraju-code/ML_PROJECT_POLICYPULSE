🏠 Welcome to PolicyPulse

PolicyPulse is a machine learning project that analyzes vehicle insurance customer data and predicts whether a customer will respond to an insurance offer.

Project Overview

  • Dataset: Vehicle Insurance Prediction Dataset
  • Total Records: 381,109
  • Total Columns: 12
  • Target Variable: Response
  • Problem Type: Binary Classification

Dataset Features

  • Gender
  • Age
  • Driving License
  • Region Code
  • Previously Insured
  • Vehicle Age
  • Vehicle Damage
  • Annual Premium
  • Policy Sales Channel
  • Vintage
  • Response

Machine Learning Workflow

  1. Data Loading – Load the original PolicyPulse dataset.
  2. Exploratory Data Analysis – Explore distributions, relationships, correlations and response patterns.
  3. Data Preprocessing – Clean, encode, handle outliers, split and scale the dataset.
  4. Linear Regression – Apply the required linear regression approaches.
  5. Logistic Regression – Build classification models with regularization.
  6. Tree Based Models – Apply tree-based machine learning algorithms.

Project Objective

The objective of PolicyPulse is to analyze customer and vehicle-related factors and build machine learning models that can predict customer response to an insurance offer.
