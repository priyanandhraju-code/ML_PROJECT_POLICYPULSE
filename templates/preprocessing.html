Preprocessing Steps

1. Remove ID

The ID column was removed because it does not provide useful predictive information.

2. Missing Value Handling

Missing numerical values are handled using the median and categorical values using the mode.

3. Categorical Encoding

Categorical variables are converted into numerical features using one-hot encoding.

4. Outlier Treatment

Extreme Annual Premium values are handled using the IQR-based clipping method.

5. Train-Test Split

The dataset is divided into training and testing datasets using an 80:20 split.

6. Standard Scaling

Age, Annual Premium and Vintage are standardized using StandardScaler.
