Preprocessing Pipeline

Sequence of transformations applied to the dataset.

1. Remove ID

The id column was removed because it is an identifier and does not provide useful predictive information.

2. Train-Test Split

The dataset was split 80:20 before learning medians, categories, IQR fences and scaling parameters from training rows only.

3. Missing Value Handling

The training medians and modes are used to replace missing predictor values in both splits. The result contains 0 missing values.

4. Categorical Encoding

Gender, Vehicle_Age, Vehicle_Damage, Region_Code and Policy_Sales_Channel use training categories; unseen test categories are handled safely.

5. IQR Outlier Treatment

Outliers in Annual_Premium were detected using the Interquartile Range method and handled using clipping.

6. Standard Scaling

Age, Annual_Premium and Vintage were standardized using StandardScaler.

IQR Outlier Analysis

Detailed calculation of the Interquartile Range for Annual_Premium.

Feature analyzed: Annual_Premium

The IQR method was applied using the training dataset. The resulting training fences were then also applied to the testing data.
IQR Formula:
IQR = Q3 − Q1

Lower Fence:
Q1 − (1.5 × IQR)

Upper Fence:
Q3 + (1.5 × IQR)

Outlier Treatment

Instead of deleting the outlier rows, the Annual_Premium values were clipped to the calculated IQR boundaries.

Therefore, values above {{ "{:,.2f}".format(prep.upper) }} were replaced by {{ "{:,.2f}".format(prep.upper) }}.

Values below the lower fence would be clipped to {{ "{:,.2f}".format(prep.lower) }}.

Lower Limit = {{ "{:,.2f}".format(prep.lower) }}
Upper Limit = {{ "{:,.2f}".format(prep.upper) }}

Annual_Premium = clip(Annual_Premium, {{ "{:,.2f}".format(prep.lower) }}, {{ "{:,.2f}".format(prep.upper) }})
