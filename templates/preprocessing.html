🔄 Preprocessing Pipeline

1. Remove ID

The id column is removed because it is an identifier rather than a predictive feature.

2. Train/Test Split

An 80:20 stratified split is performed before learning preprocessing statistics.

3. Missing Values

Numerical values use training-set medians and categorical values use training-set modes when required.

4. Categorical Encoding

Gender, Vehicle_Age, Vehicle_Damage, Region_Code and Policy_Sales_Channel use one-hot encoding.

5. IQR Outlier Treatment

Annual_Premium outliers are detected from training data and clipped using training-derived fences.

6. Standard Scaling

Age, Annual_Premium and Vintage are standardized using a scaler fitted only on training data.
