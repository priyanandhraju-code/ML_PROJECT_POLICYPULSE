🔄 Preprocessing Pipeline

Sequence of transformations applied to the dataset.

1. Remove ID

The id column was removed because it is an identifier and does not provide useful predictive information.

2. Missing Value Handling

Missing values were checked and handled. The final preprocessing result contains 0 missing values.

3. Categorical Encoding

Categorical variables including Gender, Vehicle_Age, Vehicle_Damage, Region_Code and Policy_Sales_Channel were converted into numerical features.

4. Train-Test Split

The dataset was divided into training and testing sets using an 80:20 split.

5. IQR Outlier Treatment

Outliers in Annual_Premium were detected using the Interquartile Range method and handled using clipping.

6. Standard Scaling

Age, Annual_Premium and Vintage were standardized using StandardScaler.

📊 IQR Outlier Analysis

Detailed calculation of the Interquartile Range for Annual_Premium.

Feature analyzed: Annual_Premium

The IQR method was applied using the training dataset. The resulting training fences were then also applied to the testing data.
IQR Formula:
IQR = Q3 − Q1

Lower Fence:
Q1 − (1.5 × IQR)

Upper Fence:
Q3 + (1.5 × IQR)
IQR Component Calculation Value

Q3 75th Percentile 39,443
IQR 39,443 − 24,403 15,040
Lower Fence 24,403 − (1.5 × 15,040) 1,843
Upper Fence 39,443 + (1.5 × 15,040) 62,003

🛠️ Outlier Treatment

Instead of deleting the outlier rows, the Annual_Premium values were clipped to the calculated IQR boundaries.

Therefore, values above 62,003 were replaced by 62,003.

Values below the lower fence would be clipped to 1,843.

Lower Limit = 1,843
Upper Limit = 62,003

Annual_Premium = clip(Annual_Premium, 1,843, 62,003)
